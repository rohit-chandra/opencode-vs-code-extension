## Your subscription first, an API key last

- **opencode:** `/providers` → **Sign in with a subscription** → ChatGPT Plus/Pro, GitHub Copilot, GitLab Duo or another plan. The models appear as soon as you finish in the browser.
- **Claude Code and Codex** sign in with your Claude or ChatGPT plan by default. A terminal opens, your browser asks you to confirm, and the chat notices when you are done.
- **Copilot** uses your GitHub Copilot plan through VS Code.
- **An API key** is always the last option, because it is billed per token. Keys stay in your operating system's keychain (VS Code Secret Storage), never in a settings file. Local servers such as Ollama and LM Studio need no key.

Nothing is sent anywhere except to the engine and model you chose.
