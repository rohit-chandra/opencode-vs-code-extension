## Ask about the code in front of you

- Select code, right-click, then **Explain Selection** or **Fix Selection**.
- On an error or warning, open the lightbulb and choose **Fix with OpenCode Hub**.
- `Ctrl+Alt+L` (`Cmd+Alt+L` on macOS) adds the selection to your next message.
- Type `@` in the message box to attach any file, or drop files on the chat.

The shield button under the message box decides whether the agent asks before it runs commands and edits files (**Ask**) or proceeds on its own (**Auto**).
