## Five engines, the same chat

| Engine | Uses | You need |
|---|---|---|
| **opencode** | Your `opencode` CLI | `npm install -g opencode-ai`, then `/providers` |
| **Claude Code** | Your `claude` CLI | A Claude Pro or Max plan, or an API key |
| **Codex** | Your `codex` CLI | A ChatGPT Plus or Pro plan, or an API key |
| **Direct BYOK** | OpenAI-compatible and Anthropic APIs | An API key, or a local server such as Ollama |
| **Copilot** | VS Code's language models | GitHub Copilot Chat |

Switch at any time with `/engine`. Each engine keeps its own sessions and model for the folder.
