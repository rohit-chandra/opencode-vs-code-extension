## One chat, wherever you want it

- **Side bar:** click the Oki icon in the activity bar, or press `Ctrl+Alt+O` (`Cmd+Alt+O` on macOS).
- **On the right:** type `/move right` in the chat.
- **As an editor tab:** type `/move editor`. A tab can be split, dragged beside your code or moved to its own window.

Type `/` in the message box to see every command, and `@` to attach a file from the workspace.
