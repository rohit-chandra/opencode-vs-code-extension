## Is everything in place?

`/doctor` lists, right in the chat:

- the version of OpenCode Hub, your editor and operating system
- every engine: ready, not installed, or what it is waiting for
- the selected model and connected MCP servers

If a CLI is installed but not found, set its path in settings (`opencodeHub.opencode.path`, `opencodeHub.claudeCode.path`, `opencodeHub.codex.path`) and run **OpenCode Hub: Restart Active Engine**.
